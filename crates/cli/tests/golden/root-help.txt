GBA analyzer, decompiler, and runtime

Usage: oxyboy <COMMAND>

Commands:
  info        Print header fields, hashes, and identification for a ROM
  disasm      Emit matching, re-assemblable assembly from a ROM
  analyze     Recover code and data layout and function boundaries
  lift        Lift a ROM into the intermediate representation
  recomp      Statically recompile a ROM to host code
  run         Execute a ROM in the GBA runtime
  diff        Compare interpreter and recomp-hybrid execution of one ROM
  corpus      Run the regression corpus: determinism and frame-time budgets
  suite-test  Run one external-suite ROM and decode its on-screen verdict
  trace-diff  Compare two execution traces and report the first divergence
  help        Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
